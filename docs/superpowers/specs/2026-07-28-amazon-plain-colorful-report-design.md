# 亚马逊通俗彩色全量报告设计

日期：2026-07-28

## 目标

把现有“数据完整但表达笼统”的亚马逊报告改为混合型报告：管理者能在首页快速判断经营状况，运营人员能按步骤执行优化，同时保留全部工作表、全部数据行和全部逐项分析。

成功标准：

- 首页在一分钟内回答“整体怎么样、先处理什么、为什么、预计影响什么”。
- 每条关键建议都包含后台位置、操作步骤、调整幅度、观察期、成功标准和回滚条件。
- 正文使用白话解释指标，不依赖读者理解 PPC 或数据分析术语。
- 所有有效数据都参与分析，正文突出优先项，附录包含 100% 逐项结果。
- 广告与非广告报告使用各自适用的业务语言，不把非广告数据强行解释成广告表现。
- PDF 色彩丰富但语义一致，打印和屏幕阅读均清楚。

## 推荐结构

### 1. 彩色经营驾驶舱

封面后的第一页展示：

- 总体健康等级：优秀、良好、需关注、高风险。
- 四张核心卡：数据规模、主要成果、最大风险、最大机会。
- 一句话结论：不超过三句，直接说明当前状态和首要动作。
- 红黄绿问题分布以及已覆盖数据比例。

颜色只表达固定含义：

- 紫色：章节和品牌信息。
- 蓝色：事实、规模和中性信息。
- 绿色：表现良好或明确机会。
- 橙色：需要观察或本周处理。
- 红色：高风险和立即处理。

不能只靠颜色表达等级；必须同时显示文字标签和图标，保证黑白打印及色觉差异场景可读。

### 2. 白话诊断

每个重要发现统一拆成四段：

1. 发生了什么：引用真实字段、数值、期间和对象。
2. 这意味着什么：用日常经营语言解释。
3. 为什么要处理：说明可能造成的浪费、损失或增长机会。
4. 判断依据：列出触发该结论的规则或数据关系。

首次出现专业指标时附一句解释。例如：

- ACOS：每获得 100 元销售额花了多少广告费。
- ROAS：每花 1 元广告费带来多少销售额。
- CTR：看到广告的人里，有多少人点击。
- CVR：点击后有多少人最终下单。

若上传内容不是广告报告，则根据实际列名和工作表生成通俗解释，不展示无关的广告术语。

### 3. 分阶段行动清单

行动分为“今天处理”“本周优化”“持续观察”。每项使用操作卡展示：

- 优先级与影响对象。
- 当前数据与问题原因。
- 亚马逊后台路径；无法可靠判断时明确写“请在对应业务页面定位该对象”，不得编造路径。
- 编号操作步骤。
- 建议调整幅度或安全范围。
- 观察窗口。
- 成功标准。
- 触发回滚的条件及恢复方法。

禁止使用“建议优化”“持续关注”“适当调整”等没有操作标准的孤立句子。

### 4. 图表与对比

仅在字段满足要求时生成相应图表：

- 成本、销售额、订单等核心数值概览。
- 风险等级分布。
- 高花费低回报、低转化、高曝光低点击等问题分组。
- 前后或分组对比。

图表标题必须给出一句读图结论。字段不足时省略图表并说明原因，不绘制误导性内容。

### 5. 全量逐项附录

附录继续输出全部工作表、全部解析行和全部唯一条目分析，不限制前 N 项。每项至少包含：

- 原始对象标识和来源工作表。
- 关键原始值。
- 风险等级。
- 白话结论。
- 可执行步骤及复核方法。

正文的“重点项”只是排序和导航，不影响全量分析覆盖率。报告显著显示“已分析 X/X 项”。

## 数据流与边界

本地确定性分析继续负责全量逐项计算、风险分类、通俗指标解释和基础动作模板。AI 只负责跨工作表关系、经营摘要和优先级归纳，避免 AI 超时导致逐项内容缺失。

报告生成器接收现有报告 JSON，并增加一个展示模型层，把原始结果转换成驾驶舱卡片、白话诊断、行动卡和完整附录。展示模型不得修改原始数值。

对于未知报告：

- 读取全部工作表和全部可解析行。
- 使用列名、数值类型、日期和工作表关系总结报告用途。
- 只陈述能够由源数据验证的内容。
- 无法识别的字段原样保留，并说明需要人工确认其业务含义。

## 错误与降级

- AI 不可用：仍生成完整本地分析和 PDF，并标明跨表总结使用本地规则生成。
- 某列缺失：跳过依赖该列的指标，不把缺失值当作零。
- 数值格式异常：保留原始文本并在数据质量区列出。
- 数据量很大：分段生成附录，确保所有条目输出，页面显示连续编号。
- PDF 图表失败：保留对应文字结论和数据表，不使整个报告失败。

## 测试与验收

- 先增加失败测试，验证白话字段、行动卡必填项、颜色语义和非广告报告降级行为。
- 使用广告报告及通用多工作表报告验证全量覆盖率。
- 使用现有真实报告重新生成 PDF，检查总项数与 JSON 一致。
- 抽查首页、行动页、图表页、附录首尾页以及中文换行。
- 渲染 PDF 页面为图片，确认无重叠、裁切、乱码、黑块和难以辨认的配色。
- 验证生产环境下载的新 PDF 与最新生成版本一致。

## 不在本次范围

- 不改变用户上传流程和登录体系。
- 不自动修改亚马逊后台数据。
- 不为无法从报告验证的数据承诺具体利润结果。
