# Borealos Codex 图片换模特设计

## 目标

在 Borealos「AI 画室」新增真实可用的「图片换模特」功能。用户既可以把现有模特替换为新人物或宠物，也可以只上传服装、平铺商品或商品图，让 Codex 图像通道生成穿着该商品的模特。每次默认生成两个候选，并尽量保持商品的颜色、文字、Logo、纹理、版型和配饰。

本功能只使用 Borealos 现有 Codex 图像通道，不接入 IDM-VTON、CatVTON、Kolors Virtual Try-On 或其他外部生成模型。

## 输入模式

### 现有模特换人

- 上传包含现有模特的人像或商品图。
- 系统识别人物、服装、商品和背景区域。
- 只替换人物或宠物，尽量保持服装、姿势、构图、光线和背景。

### 商品生成上身模特

- 上传服装、鞋履、配饰、宠物服装、平铺图或纯商品图。
- 系统识别商品结构及可见细节。
- 按用户选择生成自然穿着或使用该商品的人物或宠物。

### 可选目标参考

用户可额外上传一张目标人物或宠物参考图。上传时优先保持参考对象的脸部、体型、毛色和可见识别特征；未上传时按筛选条件自动创建新模特。

## 模特配置

### 人类

- 呈现：男性、女性、中性。
- 年龄：婴幼儿、儿童、青少年、青年、中年、老年。
- 地理：国家，以及对应州、省或地区。
- 外貌：自动匹配当地多样化的商业人像，或手动设置人物族群、肤色、发型、体型及其他外貌特征。

地区不会被硬编码成单一族群或肤色。自动模式应使用自然、多样、符合当地商业场景的组合，避免夸张和刻板化。

### 宠物

- 类型：猫、狗及产品支持的其他常见宠物。
- 品种：按宠物类型选择具体品种。
- 可设置体型、毛色、年龄阶段和场景。

### 商品与场景

- 商品类型：上衣、裤装、裙装、套装、泳装、内衣、鞋履、帽子、配饰和宠物服装等。
- 场景：电商白底、棚拍、街拍、居家、户外等。
- 未成年人仅允许正常童装、家庭及商业场景。系统必须拒绝成人化、暴露、性暗示或其他不适宜内容。

## 页面流程

功能作为「AI 画室」内独立的「图片换模特」页签。

1. 上传素材：支持点击、拖拽、最多十五张批量上传，显示真实上传进度。
2. 选择输入模式与模特：人物或宠物、年龄、地区、族群或品种、服装类型和场景。
3. 可选上传目标参考图。
4. 生成前展示任务数量、每张两个候选和可能发生的 Codex 调用。
5. 任务显示上传、素材识别、候选一生成、候选二生成、质量检查及完成等真实阶段。
6. 结果页并排展示两个候选，支持单张重做、下载、加入作品库和保存为模特模板。

同一原图可反复更换条件重新生成，所有成功结果和失败尝试均保留为不可覆盖的版本历史。

## 生成与质量流程

1. 读取图片尺寸、方向和安全元数据。
2. 识别商品主体、服装区域、人物或宠物、背景及姿势。
3. 提取不可修改清单：颜色、Logo、文字、花纹、领口、袖型、纽扣、鞋型、配饰和其他可见结构。
4. 根据用户条件生成结构化 Codex 图像编辑指令。
5. 串行生成两个独立候选，成功一个即保存一个，避免整批丢失。
6. 对候选执行自动质量检查：
   - 人物、宠物、年龄和地区条件匹配度；
   - 商品颜色、Logo、文字、纹理和版型保真度；
   - 身体、手脚、脸部、毛发、穿着关系和遮挡是否自然；
   - 输出比例和尺寸是否符合原图或用户设置。
7. 质量不足的候选明确标记问题并建议单张重做，不得把失败图标记为高质量完成。

仅使用通用 Codex 图像通道无法承诺像素级商品一致。页面必须显示服装保真度和可见差异提醒，尤其针对小文字、细密花纹和原图不可见结构。

## 任务、恢复与隔离

- 每个任务保存用户、源图、目标参考、配置、两个候选、质量结果、失败原因、重试次数和版本历史。
- 每个候选拥有独立幂等键，服务重启后不重复生成已成功候选。
- 支持暂停、恢复、取消未提交候选和失败重试。
- 批量任务逐张隔离，一张失败不阻断其余图片。
- 文件、任务、结果和模板均按用户隔离；接口不得接受其他用户目录的源图。
- 接入全局任务中心和灵动岛，进度只由真实阶段与已完成候选驱动，不使用计时模拟。

## 错误处理

- Codex 不可用、超时、网络中断、内容拒绝或结果损坏时显示真实原因。
- 上传中断可单张重试；服务端必须清理中断产生的部分文件。
- 生成失败保留源图和配置，用户无需重新上传。
- 一个候选失败时保留另一个成功候选。
- 不显示永久灰色占位结果，不把排队误标为生成。

## 验收

- 两种输入模式均可完成真实生成。
- 人物、宠物、全部年龄段、国家与州省地区联动、人物族群和宠物品种均可使用。
- 每张默认生成两个候选，十五张批量任务可逐张完成并保留历史。
- 目标参考图为可选项，并在提供时影响生成结果。
- 上传、识别、两次生成、质检和完成均显示真实进度。
- 同一原图重复生成不会覆盖旧版本。
- 暂停恢复、断网、超时、服务重启和失败重试不会重复收费或丢失成功结果。
- 多用户之间不能读取或使用彼此素材。
- 未成年人安全规则不可绕过。
- Windows、macOS、手机和平板布局均可操作。
- 全部功能进入作品库、模板中心、全局任务中心和灵动岛。
