# Borealos 正式安装包、官网发布与模板中心设计

## 目标与顺序

全局任务中心与灵动岛完成、复审并合并后，自动执行以下工作：

1. 重建 Windows、macOS、Android 手机和 Android 平板正式安装包；
2. 使用现有平台证书完成签名及 macOS 公证；
3. 在干净环境完成安装、升级、卸载和核心功能验收；
4. 更新官网的四个平台下载入口；
5. 将模板中心重做为以缩略图浏览为主、点击后进入功能页的资源中心。

任何平台失败只阻止该平台发布，不得把部分成功显示为全部成功。发布流程不删除上一稳定版本。

## 发布矩阵

### Windows

- 产物为正式安装版 EXE，不发布免安装压缩包作为主入口。
- 支持选择安装目录、开始菜单、桌面快捷方式、覆盖升级和标准卸载。
- 使用现有 Windows 代码签名证书。
- 安装器和主程序均验证签名。

### macOS

- 产物为 DMG。
- 优先提供 Intel 与 Apple Silicon 通用版本；若现有技术栈无法生成通用包，官网分别展示架构。
- 使用现有 Apple 签名身份并完成公证。
- 实测挂载、拖入 Applications、首次启动及 Gatekeeper 状态。

### Android 手机

- 独立签名 APK。
- 使用手机布局：单列优先、底部导航、紧凑操作区。
- 与平板版共享账号、服务端数据、核心功能和版本语义。

### Android 平板

- 独立签名 APK。
- 使用平板布局：双栏、侧边导航、工作区优先。
- 与手机版共享账号和服务端数据，但构建产物与界面配置独立。

## 版本与发布清单

四个平台使用同一个 Borealos 产品版本。发布清单逐项保存：

- 产品版本和构建号
- 平台、架构和最低系统版本
- 文件名、大小、SHA-256和下载地址
- 签名、公证和安装验收状态
- 构建提交和构建时间
- 是否为当前推荐版本

官网只从已验收的发布清单读取推荐版本。旧版本保留为可回滚产物，不在自动流程中删除。

## 自动发布流水线

`灵动岛通过 → 合并稳定代码 → 全量测试 → 四平台构建 → 签名/公证 → 干净环境安装验收 → 生成清单 → 更新官网 → 生产下载复测`

流水线要求：

- 每个平台拥有独立状态和日志。
- 构建、签名、安装验收和官网发布均产生真实任务中心事件。
- 未知阶段使用不确定进度，不模拟百分比。
- 签名凭证只通过构建环境注入，不进入仓库、安装包日志、浏览器或构建产物。
- 官网更新前必须验证文件哈希、签名和安装结果。
- 官网更新失败时保留现有下载入口。

## 官网

下载区域展示 Windows、macOS、Android 手机、Android 平板四张平台卡片。每张卡片显示：

- 最新可用版本
- 架构或设备类型
- 文件大小和发布日期
- 安装按钮
- SHA-256复制入口
- 安装说明和系统要求

不可用的平台显示上一个稳定版及当前新版状态，不显示损坏或未验收产物。

## 模板中心定位

模板中心是资源发现入口，不再在列表页复制各个功能的上传、参数和生成表单。交互采用“浏览卡片 → 选择模板 → 进入对应功能页 → 自动载入配置”。

## 信息架构

### 场景导航

- 营销
- 电商
- 设计
- 办公
- 开发
- 全部

### 功能筛选

- 图片
- 视频
- 音频
- 文案
- 电商
- 亚马逊
- 工程

同时支持搜索、收藏、最近使用和全部模板。场景与功能可以组合筛选。

## 模板卡片

列表页卡片只显示：

- 16:9或统一系统比例的缩略图
- 模板名称
- 对应功能
- 最多三个简短标签
- 收藏状态

不显示长说明、完整提示词、参数表或操作按钮堆叠。

点击卡片直接进入对应功能页，不增加中间详情页。功能页自动载入模板的提示词、默认参数、示例素材引用和功能配置；用户确认后再执行生成。

## 响应式布局

- 手机：一列或两列紧凑卡片，底部导航。
- 平板：多列卡片，侧边分类，可保留筛选面板。
- 电脑：自适应多列网格，左侧分类和顶部搜索。
- 卡片尺寸一致，图片使用等比裁切，不拉伸缩略图文字和内容。

## 模板注册表

模板不硬编码在页面中。统一注册表保存：

- `templateId`
- `name`
- `thumbnail`
- `sceneCategories`
- `functionType`
- `targetRoute`
- `targetFeature`
- `preset`
- `tags`
- `status`
- `version`

路由层验证 `targetRoute` 和 `targetFeature` 属于允许列表。模板下线不删除用户的历史使用记录。

## 错误与回退

- 缩略图失败时显示统一占位图，不改变卡片比例。
- 模板不存在或下线时返回模板中心并显示原因。
- 目标功能不可用时禁止开始生成，并提供状态说明。
- 预设版本不兼容时迁移到当前版本或明确要求用户重新选择。
- 收藏和最近使用失败不阻止模板功能使用。

## 验收

- Windows完成安装、覆盖升级、卸载及签名验证。
- macOS完成DMG挂载、安装、首次启动、签名和公证验证。
- 手机和平板APK分别完成安装、登录、核心功能和布局验收。
- 官网四个入口下载文件与发布清单SHA-256一致。
- 上一稳定版本仍可回滚。
- 模板中心首屏只显示卡片浏览和筛选。
- 每个模板进入正确功能页并载入正确预设。
- 手机、平板和电脑无横向溢出，缩略图不变形。
- 搜索、场景、功能、收藏和最近使用均有测试。
- 模板下线、图片失败、目标功能不可用均有明确回退。
