# Borealos Mac 版打包说明

## 这是什么

解压后跑一条命令，得到真正的 `Borealos-v5.0-mac.dmg` 安装包（把 Borealos 网页应用包成原生 Mac App）。

**零依赖：不需要装 Node.js，不需要装 Homebrew**——只用 macOS 自带工具，Electron 运行时由脚本自动从国内镜像下载（约 100MB，仅第一次）。

## 步骤（共 2 步）

1. **解压** `borealos-mac.zip`，得到 `nexa-mac` 文件夹

2. 打开 Mac 的「终端」，执行：
   ```bash
   cd 下载/nexa-mac
   bash build-dmg.sh
   ```
   （路径按你实际解压位置调整；也可以先把文件夹拖进终端窗口自动填路径，再回车补上 `bash build-dmg.sh`）

   等几分钟，文件夹里出现 **`Borealos-v5.0-mac.dmg`**

## 安装

双击 DMG → 把 Borealos 拖进 Applications → 启动台/Dock 里就有 Borealos 了。

正常情况下双击就能打开（脚本是 curl 下载的文件，不带浏览器隔离标记）。万一提示「无法验证开发者」：在 App 上 **右键 → 打开** 即可。

## 说明

- 自动识别 Intel / Apple 芯片（M 系列）
- App 是壳，真正的服务和数据在网关服务器（`https://borealos.dev`）上，打开后登录你的账号
- **菜单栏胶囊**：启动后顶部菜单栏出现胶囊图标，点开是毛玻璃状态卡（网关状态 + 各模型真实用量 + 更新时间），右键有快捷菜单
- **关掉窗口胶囊照样活**：状态由 App 后台每 15 秒独立刷新，不依赖主窗口；窗口最小化/关闭都不影响；网关断开/恢复时 macOS 原生通知提醒，胶囊图标同步变空心/实心
- 网关关机或断网时 App 打不开界面，属正常
- 网页端更新后 Mac App 自动跟随，不用重新打包

## 不想打包？

Mac 上用 Edge/Chrome 打开 `https://borealos.dev` → 点地址栏右侧的「安装」图标 → 一样能装进 Dock 和启动台。
